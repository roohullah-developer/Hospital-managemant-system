# Hospital Management System

A simple Hospital Management System built using Python.

## Features

- Manage patients
- Manage doctors
- Manage appointments
- Store medical records

## Technologies

- Python

## Project Structure

- patient.py - Patient management
- doctor.py - Doctor management
- appointment.py - Appointment management
- medical_record.py - Medical records
- patient.txt - Patient data

## Status

This project is currently under development.
